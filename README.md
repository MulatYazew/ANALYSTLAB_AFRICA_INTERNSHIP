# AnalystLab Africa — Machine Learning Internship

12-week progressive Machine Learning internship. Each week's deliverable is
built on its own branch off `main` and merged in once complete, so `main`
always reflects the accumulated, reviewed work.

See [WORKFLOW.md](WORKFLOW.md) for the branching convention and the exact
steps to start, submit, and merge each week.

## Project layout

```
notebooks/   One notebook per week: AnalystLab_Africa_WeekN_<Topic>.ipynb
dataset/     Local datasets (gitignored — not committed)
scripts/     Helper scripts (e.g. scripts/new-week.sh)
```
